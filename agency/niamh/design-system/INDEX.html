Design Laws
Inviolable. Every build. Every brand.
🚫
No type effects. Ever.
No text-shadow, no gradient text, no stroke on type. Display type is roman by default. Italic only for cast role lines.
🚫
No raw hex values in code.
Every colour is a CSS token. var(--blue) not #1F4598. Token names are the source of truth.
🚫
No coloured shadows.
Shadows are soft, cool-grey. Only --shadow-card has a faint blue cast (product cards only). Never coloured.
🚫
No bounces. No infinite loops.
All motion uses --ease (calm ease-out). Duration: 140–420ms. No springs, no looping animations, no bounces.
✅
Documentary photography only.
No SVG illustration. No mascots. Real people, real moments. Credibility comes from authenticity.
✅
Square corners on campaign frames.
border-radius: 0 on all editorial/full-bleed campaign frames. Only product cards round at --radius-lg (18px).
⚠️
Ibucap: zero medical figures.
No doctors, nurses, pharmacists — real or illustrated. No superheroes. No mascots. PPB / NAFDAC compliance. Claim: "The Power of Three in One." Only.
✅
Eyebrow → Headline → Support. Always.
Wide-tracked UPPERCASE eyebrow first. Serif headline. Source Sans body. This hierarchy never breaks. Orange or blue eyebrow only.
