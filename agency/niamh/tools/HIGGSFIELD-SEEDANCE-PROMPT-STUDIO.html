What this is

Higgsfield runs our video through Seedance 2.0. A great Seedance prompt is one clean paragraph of pure visual description in a fixed order: Style & Mood → Dynamic Description → Static Description → camera block → diegetic audio. You pick a cinema mode; the mode locks the camera, lens family, movement, filtration and grade so every clip in a campaign shares the same visual DNA. The converter writes that paragraph for you — this guide explains the choices.

The five cinema modes

ModeUse when the scene is…MovementGrade / look
M1 NarrativeReal-world, lived-in — streets, kitchens, cars, homes, exteriorsHandheld, slight breath, occasional slow dollyKodak 250D, teal-amber split, anamorphic
M2 StudioWhite void, editorial, fashion film, crafted sets, performance-on-setLocked-off + optional 4–6" slow pushSaturated editorial, Cooke warmth, blooms on chrome
M3 ActionCombat, chase, stunts, debris, smoke, dustHandheld + shaky throughout, no stable shotsGritty doc-sci-fi, dusty haze, palette per scene
M4 PerformanceStage, arena, festival pit, crowd + stage lightingPit-photographer, orbital, hard cutsCool desaturated + warm bloom, stage colour cast, haze
M5 AtmosphericEmpty / abandoned / landscape / weather — no humansLocked-off or extremely slow push/driftPalette-driven (give hex), weathered materials, negative space

All modes share an ARRI body + anamorphic or Cooke glass. What changes is movement, filtration, grade, palette and texture — never plastic, never commercial gloss. Every frame looks captured on a camera that has lived a little.

Lens guide

  • 32 / 40mm — wide establishing, full-body, group, environment
  • 50 / 55mm — medium portrait, two-shot, dialogue framing (the safe default)
  • 75mm — tight editorial portrait, single-character isolation
  • 100mm — extreme close-up: eyes, lips, jewellery, fabric texture

Diegetic audio — do

  • Footsteps (name the surface), fabric rustle/whip
  • Breath — steady, ragged, sharp inhale
  • Object sounds — door, glass, metal, paper
  • Ambient — wind, rain, traffic hum, room tone, fire crackle
  • Crowd / stage — cheering, mic handling, haze hiss

Diegetic audio — never

  • Song names, artist names, lyrics
  • "Music plays", "soundtrack swells"
  • Score words — orchestral, synth, strings
  • Genre cues — "beat drops", "guitar"

Want music in the cut? Upload the track as a separate audio reference in Higgsfield. The prompt stays diegetic.

House rules the converter enforces for you

  • No em dashes. They break Higgsfield's JSON — the studio auto-converts them to hyphens.
  • No names. Describe people by hair, wardrobe, markers — "the rose-pink haired woman in the cropped tank", never a name.
  • No brands. Generic descriptors — "black three-stripe sneakers", not the label.
  • No age words. Avoid boy/girl/child/kid/teen/young/old — describe by role and clothing.
  • No image tags. No @image, no <<<id>>> — reference images attach in the Higgsfield UI.
  • Self-contained. No "as established earlier" / "matching the last scene". Every prompt restates its world fresh.
  • Visual only. No meta-commentary about why a shot works — only what is visible in frame.

The loop

1 · Pick the mode and fill the fields.  2 · Render and copy the paragraph.  3 · Paste into Seedance on Higgsfield.  4 · Attach your reference images (or pick them from your Higgsfield library) in the UI.  5 · Generate. House clip specs: 9:16, 720p, and audio handled in post.
